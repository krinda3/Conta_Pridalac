# Las pantallas del programa

Esta lista la genera el propio programa a partir de su menú: siempre coincide con lo que hay. Dentro de una empresa, cada nombre es un enlace a su pantalla. Para ver **cómo se usan juntas** y en qué orden, mire el tema [El cierre del trimestre](tema:trimestre).

## Cómo funcionan las listas

- **Doble clic** en una fila para verla o editarla. En las listas de solo lectura, el doble clic enseña el detalle.
- La **lupa** de arriba filtra por cualquier texto de las columnas; el título de cada columna ordena (otro clic, al revés).
- **PDF** y **Excel** exportan lo que se está viendo, con el filtro y el orden aplicados.
- Donde existe, **Importar Excel** carga filas desde una hoja (se enseña una vista previa y no se guarda nada hasta confirmar).
- Los botones de la barra (por ejemplo «Aplicar propuestas» o «Hacer una copia ahora») abren un cuadro que explica qué va a pasar antes de hacerlo.

## Lo que se genera solo

Los asientos de las facturas, de los movimientos de banco, de las liquidaciones de IVA y del cierre **se crean solos**: no se teclean ni se editan a mano. Si una factura está mal, se corrige la factura y el asiento se regenera. Los **asientos manuales** son para lo que no tiene factura ni banco (nóminas, seguros, ajustes), y se puede usar una [plantilla](tema:contabilidad#asientos-manuales-y-plantillas).

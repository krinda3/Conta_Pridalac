# Glosario

Los términos que usa el programa, ordenados alfabéticamente.

| Término | Qué significa |
|---|---|
| **Acuse de recibo** | El PDF que devuelve el Registro Mercantil al recibir una legalización o un depósito. De él se leen el identificador, la referencia, el número de entrada y la fecha |
| **Apertura** | Los asientos que traen los saldos de un ejercicio al siguiente. Los crea el programa al cerrar el anterior |
| **Apunte** | Cada línea de un asiento: una cuenta, un importe y si va al Debe o al Haber |
| **Asiento** | Un conjunto de apuntes que cuadra (Debe = Haber). Casi todos se generan solos |
| **Auditoría** | Las comprobaciones de que la contabilidad es coherente. Los errores impiden cerrar el ejercicio |
| **Base imponible** | La cifra sobre la que se calcula un impuesto. En el IS, el resultado contable corregido y tras compensar bases negativas |
| **Base imponible negativa** | La pérdida fiscal de un año, que se puede compensar con beneficios de años posteriores |
| **Borrador** | Un modelo calculado y guardado, sin fichero ni presentación |
| **Categoría de gasto** | Etiqueta de análisis de una factura recibida (gas, electricidad, abonos, labores…) que no cambia ningún asiento. Sirve para el listado [Gastos por categoría](pantalla:gastos-categoria) |
| **Conciliar** | Emparejar cada línea del extracto del banco con la factura, el vencimiento o el asiento que explica. Es el núcleo del cierre del trimestre |
| **Copia de ensayo** | Copia de la contabilidad marcada de forma irreversible para practicar: no puede generar ficheros para la sede ni registrar presentaciones |
| **Corrección al resultado** | Lo que se suma o resta al resultado contable para llegar a la base imponible del IS (por ejemplo, las multas, que no son deducibles) |
| **CSV** (de la sede) | El código seguro de verificación que da la AEAT a cada presentación |
| **Cuota íntegra** | El impuesto resultante de aplicar el tipo de gravamen a la base imponible, antes de deducciones y pagos |
| **D2** | El programa de los Registradores con el que se depositan las cuentas anuales |
| **Depósito de cuentas** | Entregar en el Registro Mercantil las cuentas anuales aprobadas, un mes después de su aprobación |
| **Diseño de registro** | El documento de la AEAT que define, posición a posición, cómo es el fichero de cada modelo |
| **Domiciliar** | Pagar un modelo cargándolo en el banco; tiene un plazo de presentación más corto |
| **Ejercicio** | El año contable de la empresa. Abierto (se trabaja) o cerrado (no admite cambios) |
| **Entidad patrimonial** | Sociedad cuyo activo, en más de la mitad, no está afecto a una actividad económica. No puede usar el tipo reducido de microempresas |
| **Extracto** | Las líneas que dice el banco que pasaron. Es la referencia contra la que se comprueba la contabilidad |
| **Fecha contable** | El día en que una factura cuenta en la contabilidad y en el IVA |
| **Huella** | Un código que cambia si cambia lo que identifica. Se usa en el registro de cambios, en los ficheros generados y en los ZIP del Registro Mercantil |
| **Información de la presentación** | El PDF de la sede de la AEAT con el justificante, el CSV y la fecha de una presentación |
| **IRUS** | El identificador único de la sociedad en el Registro Mercantil (13 cifras) |
| **Justificante** | Dos cosas distintas: el **documento de una factura** (PDF o imagen que la acredita) y el **número de justificante** que da la AEAT a una presentación |
| **Legalia2** | El programa de los Registradores con el que se legalizan los libros |
| **Libro Diario / Mayor** | El diario ordena los apuntes por fecha; el mayor los agrupa por cuenta con su saldo |
| **Liquidación del IVA** | El asiento que regulariza el IVA de un periodo |
| **NIF** | Número de identificación fiscal |
| **NRC** | Número de referencia completo: el justificante de pago de un modelo que se paga por ingreso en lugar de domiciliarlo |
| **Pago fraccionado** | Cada uno de los tres pagos a cuenta del Impuesto sobre Sociedades del año (modelo 202) |
| **Perceptor** | Quien cobra una retención del IRPF (un profesional, un arrendador): entra en el 111 y el 190 |
| **Prorrata** | Porcentaje de IVA deducible cuando una empresa tiene operaciones con y sin derecho a deducir |
| **Regularizar** | Llevar los ingresos y gastos del año a la cuenta de pérdidas y ganancias para obtener el resultado |
| **Rectificativa / complementaria / sustitutiva** | Las tres formas de corregir un modelo ya presentado |
| **Registro de cambios** | La lista, que no se puede alterar, de todo lo que se ha dado de alta, cambiado o borrado en los datos |
| **Retención** | Parte de un pago que se retiene a cuenta de un impuesto (IRPF) y se ingresa en Hacienda |
| **Subcuenta** | La cuenta contable de último nivel, la única que admite apuntes (8 dígitos por defecto) |
| **Tipo de gravamen** | El porcentaje del IS que se aplica a la base imponible (25 % el general) |
| **Titular real** | Persona que posee o controla más del 25 % de una sociedad. Se declara en el depósito y en el modelo 200 |
| **Trimestre de trabajo** | El trimestre con el que se trabaja el cierre: todas las pantallas del trimestre se limitan a sus fechas |
| **Vencimiento** | Lo que queda por cobrar o por pagar de una factura, con su fecha |
| **Verifactu** | Programa aparte con el que se reconocen las facturas recibidas en PDF y se llevan las emitidas. Conta carga sus Excel |
| **Ventana** (normativa) | La época del año en que suele salir un diseño nuevo, a partir de la cual el programa avisa de que hay que revisarlo |

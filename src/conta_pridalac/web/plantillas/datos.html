Usar otra carpeta que ya tiene datos

Por ejemplo, la carpeta de datos de otro equipo (en un disco externo o en una carpeta sincronizada), o una que se movió de sitio. Tiene que contener una subcarpeta bd con las bases de las empresas. No se copia ni se borra nada: sólo se cambia cuál se usa.

Mover los datos a otra carpeta

Copia todo (bases, justificantes y copias) a una carpeta vacía o nueva, comprueba que la copia es idéntica (integridad de cada base y huella de cada fichero) y sólo entonces pasa a usarla. La carpeta antigua no se borra: queda con una nota (MOVIDO_A.txt) por si algo no cuadra. Puede tardar varios minutos si hay muchos justificantes.

Si la carpeta se sincroniza (Drive, OneDrive, Dropbox) o está en red

  • Un solo equipo a la vez. Conta pone un candado en la carpeta para no abrirse desde dos ordenadores a la vez; si el otro equipo se cerró mal, se puede forzar desde la pantalla de bloqueo.
  • Cierre Conta antes de cambiar de equipo y espere a que termine la sincronización (el fichero del candado y las bases tardan en llegar al otro ordenador).
  • En Drive, elija «Mantener los archivos sin conexión» (no «Transmitir»); una base abierta a medio descargar se estropea.
  • Si aparecen ficheros «copia en conflicto» junto a las bases, no los borre: avise a quien mantiene el programa.
